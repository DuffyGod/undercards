# 规则、经济与裁定边界

按需查阅：构筑与区域、经济计算、关键词、对象生命周期、位置、未知队列。七 SOUL 的精确被动在 SKILL.md；查询 `soul` 可取得英文快照原文。

## 构筑与区域

- 25 张主牌；2 个普通神器或 1 个传奇神器；初始怪物共享，法术限 SOUL。BASE／COMMON／RARE 同名 3，EPIC 2，LEGENDARY／DT 1。
- Wiki 区分 Ranked 总计 1 张 DT，Standard／Custom 每种 DT 各 1；后两模式仍须核对实际配置。DT 怪物自带 Silence 免疫，不能因序列化状态未列出就否定。
- 30 HP；每侧四格；手牌最多七张，满手 Draw 会 Erase；空库 Draw 触发疲劳，次数对应 1、2、3……伤害。生成牌放不下、满场召唤及 Catch 释放失败未取得统一实现规则。
- Wiki 写起手三张、可换牌及回合开始抽牌，本地支持正常抽一张。首回合例外、换牌是否排除换掉的牌、神器起手效果与抽牌先后，未实测完整流程。
- 牌库、手牌都有顺序；dustpile 是各玩家自己的死亡区。不要把回库、Erase、Catch 也登记为普通死亡。
- 神器、任务及格子附魔不占怪物格。初选神器限制不表示局中只允许两件；新神器替换规则和总数上限未知。

## 金币计算

普通规则，n≥1：

```text
A(n) = min(n,10)
B(n) = min(n,10) + 1 if n ∈ {1,3,5,7,9}, otherwise min(n,10)
双方开局余额 = 1
行动前余额 = 上次剩余 + 基础回合收入 + 已结算的额外收入 − 已结算的额外支出
```

一直不花钱时：

- n≤10：先手余额 `1+n(n+1)/2`，后手再加 `ceil(n/2)`。
- n>10：先手 `56+10(n−10)`，后手 `61+10(n−10)`。
- 算例：第 1 回合 2／3，第 3 回合 7／9，第 10 回合 56／61，第 11 回合 66／71。

该公式排除 SOUL、神器、卡牌、减费和 Program 开支；n 不是双方合计行动次数。常规收入封顶 10 后，后手不再有奇数回合补偿。

Integrity：本地“past turn 10 cap=11”结合 Wiki 的收入解释，模型采用第 11 回合起基础收入 11，尚未实测。条件奖励检查**本回合实际支出是否超过上回合**，首回合不给。不能仅按打出的卡牌基础费相加或无条件每回合加一。

金币留存使大费牌可提前打出：先手不花钱到第 4 回合有 11，后手第 3 回合有 9；这不是打大怪的普遍推荐，因为保存期间可能丢场面。Program 或额外神器支付也会消耗余额，例如 Shop 的回合末召唤需再花 3G。

来源：本地 `tutorial-17`；[Wiki 入门页](https://undercards.fandom.com/wiki/Welcome%21)；[2025-04-20 玩家算例](https://www.reddit.com/r/UnderCards/comments/1k3rcma/what_is_going_on_with_gold/)。收入文字与初始余额／留存证据层级不同，没有读到服务器代码。

## 触发词

| 词 | 快照含义与分析影响 |
|---|---|
| Magic | 怪物被 Play 到棋盘触发；效果 Summon 不自动触发 |
| Dust | 死亡触发；返回手／库不算死亡 |
| Turn start／end | 拥有者回合开始／结束，不自动指双方每半回合 |
| Turbo | 被 Draw 时触发；Wiki 补充满手过抽仍触发，缺当前实测 |
| Support | 另一友军攻击**前**触发，可能改变那次攻击身材 |
| Shock | 自己施放基础费≥2 的法术后；减费不改变基础费。Wiki 说效果代施法不触发，该排除条件未独立实测 |
| Synergy | Play 时，检查本回合已经 Play 同种族友军，不把所有 Summon 混算 |
| Need | 所述条件约束 Magic；按当下区域检查，条件失效不等于禁止打出怪物本体 |
| Delay | Play 当回合结束执行，提前死亡／离场也执行；不要改成普通留场 Turn end |
| Program(x) | 有 xG 才再付 xG 触发，不是仅检查入场费用 |
| Loop(x) | Play 后若 x≥1，加一张 Loop 少 1 的副本入手；不是自动把副本再施放 |
| Bullseye | HP 恰为 0 且击杀，不接受溢出打至负数 |
| Switch | 按触发时左右位置选分支；Endgame 对 Piece 有双分支例外 |
| Quest／Goal／Reward | 开局由任务怪启动任务，累计目标后执行奖励；进度和重复奖励按单卡文字 |
| Flowery Power | 该牌 Need 恒成立，不等于立即施放 Magic |

完整快照另含 Future、Thorns 及辅助提示，有文本不等于目前有普通卡实际引用。用查询获取定义，别凭词条存在推断环境里有该套牌。

## 战斗、状态与伤害

| 状态 | 含义 |
|---|---|
| Taunt | 怪物攻击先处理嘲讽；不默认限制全部法术 |
| Charge／Haste | 入场可攻击；Charge 可打玩家并覆盖 Haste，Haste 只打怪物。攻击后移除；跨对方回合生成时移除时点有文字差异 |
| Armor | 每次伤害减一，不是一次性盾 |
| Dodge(x) | 抵消 x 个伤害实例，不是扣 x 点总伤害 |
| Invulnerable | 免疫伤害；不由此推断免疫 Kill、Erase、HP 数值改变 |
| Transparency | 不可指定，优先于 Taunt，拥有者回合开始移除；不默认免疫随机／群体效果 |
| Darkspawn | 无法被法术指定，且不受法术伤害；不等于一切效果免疫 |
| Disarmed／Paralyze | 不能攻击／下个己方回合不能攻击；强制攻击、连麻痹及多状态组合需具体裁定 |
| Silence | 移除状态、禁用能力；DT 免疫。基础值变化和跨区修改的清理细节缺实现，不能说重置到印刷卡面的一切字段 |
| Candy | 己方回合末治疗此怪三点 |
| Wanted | 临死前给对手 1G |
| KR | 临死前给击杀者 +1/+1；无击杀者或击杀者在拥有者回合内死亡，改给另一个随机敌怪 |
| Mold Spore | 己方回合末计数加一；死亡给对手召唤攻防等于计数的 Moldsmal |

通常普通单位每回合自主攻击一次，卡牌可赋予额外／强制攻击。不能从此推出所有攻击指令与状态的统一优先级。

## 对象与位置

- Die／Kill、伤害致死、Erase、Return、Catch 各自保留事件类型。Catch 保存副本，由 Release 指定释放位置与归属；不补写没有依据的全部字段复制规则。
- 当前／最大／基础数值分开；对 HP 的直接减值不改写成 DMG。Copy、Exact copy、base-stat rewriting 不合并。
- Generated 是本局来源；非 TOKEN 也可以被生成，生成 TOKEN 只是两者交集。牌组条件常检查 non-Generated，生成的同名或其他职业牌未必破坏它。
- 四格普通攻击可以选目标，但效果会检查正前方、相邻、左右、最左／最右。前两格为左侧是合理推断，未取得判定公式。
- 附魔跟随格子，不跟随单位。可用查询 `enchant --name ...` 获取精确效果。
- `target=ALL` 是宽目标枚举，不是群体施法；例如 Gaster Blaster #351 文字只允许怪物或自己。

## 不应伪造的统一裁定

同时死亡／同时致死、触发器队列、满格召唤、满手 Add、Catch 释放失败、跨区对象保存、总回合上限和平局仍缺完整规则。若用户要求推演这些边界，给出已知条件及不同裁定造成的分歧；若用户要求实现模拟器，明确假设并让这些规则可替换。
