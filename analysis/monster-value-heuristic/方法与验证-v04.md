# 通用 Value 建模：方法与当前验证

更新：2026-10-08。数值入口 unified_value 0.3.1；账本 context_value 0.4.0；资源桥 0.2.0。本报告记录一个已运行的迭代版本，仍不足以给全卡池可靠排名。规则来自2026-10-05本地快照，不含线上环境胜率数据。

## 评价对象与尺度

主分数评价的是：**同一套公开状态和构筑先验下，持有并考虑部署这张卡的条件报价，扣除标价后还剩多少。** 它不等于当前余额变化、实际持有概率或胜率。另显示立即可支付比例、角色差异、可选择不用的净收益和未报价状态。

尺度可以与Gold相连，但不能把设计尺度称为实测兑换率。本版将Aaron印刷6/5主体锚定5 model-G，只决定尺子的长度，不给Aaron“强牌”标签。扣费严格按卡面一次扣除，因此相同局面、时机和效果下，少付1G就是报价差多1 model-G；等待与额外手牌占用可能改变最优部署时机。

## 身材与攻击临界线

参考集合为普通4–7费怪物的印刷身材，按每个费用层等权、层内等权。文字不进入参考质量，集合不是天梯使用分布。

令p为某对手任务的打脸用途先验，参考目标HP为H，攻击的有效量为 `p*A+(1-p)*E[min(A,H)]`。连续身体项为 `alpha*sqrt((有效攻击+0.5)*自身HP)`，另加权重0.4的击杀线、存活线及二者联合门槛。alpha由上述尺度锚决定。

这使过量攻击贬值，同时允许新击杀线附近的边际上升。上一轮共同函数的HP7合成例中，6→7ATK边际为0.250/0.276/0.322/0.276 model-G（aggro/control/combo/midrange），均低于0.77。不能因此声称所有实际7/7都比6/7恰好多这个值：攻击权限、增益暴露、战场目标和终局会改变增量。

## Magic与攻击共享同一本账

有限窗口是当回合Magic→可选Haste怪物攻击→一次合成对手回应→下一己方回合一次普通攻击。Magic目标和早攻击在未知回应前决定；后续攻击只读取已观察的回应。Haste不能早打脸，Taunt限制攻击，Dodge按实例消耗，Armor按实例减伤。

三个世界为：P0印刷普通主体与原场面；Pmid同一主体、已选Magic完成；P1同一Magic完成并保留关键词。总增量为 `Phi(P1)-Phi(P0)`，分解为直接即时资源变化、`Phi(Pmid)-Phi(P0)-直接变化`、`Phi(P1)-Phi(Pmid)`。不再额外增加整只移除奖励、关键词奖金或第二份攻击伤害。

Phi使用剩余主体/敌怪的共同身体函数、己方HP、敌方HP及对手剩余现金的显式权重；对手现金损失不是我方到账。其它友军受到Magic伤害的身体损失也只记一次。其它友军尚不参与防守行动，有Taunt时拒绝该局部模块。当前回应仍只有一名敌怪攻击，低估多攻击频率的风险保留；付费沉默/伤害是合成回应，未纳入真实反制随从本体。

低HP终局不换算为有限Gold。独立复核发现纯关键词入口未读给定HP，而加0伤害Magic后读取HP，两条不一致；现已统一并通过反例测试。尚未遍历所有未被选中的可选斩杀路径，因此终局机制仍不能宣布全面完成。

## 时机、构筑与密度

默认面板是四对手任务×三个阶段×两个资源模板×三个独立场面，共72状态。大手牌不再自动意味着弱敌盘。所有卡使用相同权重；不可支付的状态保留，不能删掉后把剩余状态重归一化。

枚举0到3个额外等待回合；按明确收入/留存及可用于候选的未来收入比例判断可支付性。等待只折损正总收益，不把未来标价折成便宜现金；相对于释放一个手牌格，只有确实增加的自然烧牌才收额外容量损失。未来牌身份未知，场面暂时冻结，不能把此枚举视为对局预测。

资源桥按25牌费用分布与公开支出策略抽样，保留每阶段全部非空手Gold/手数联合频率，再与相同角色/独立场面交叉。每桶一个中位近邻代表只供查看，不参与数值积分。独立反例：49%样本G6/H3、51%样本G7/H3，6费卡立即可支付权重1、7费卡0.51；新版原样保留，旧单代表会把两者都算为1。跨桶与故意不一致桶权重反例也没有发生重复乘权。

资源样本仍未条件于这张候选实际留在手中，阶段权重和平均抽牌净收益也仍为公开先验。相同费用、不同抽牌质量的构筑不能仅靠此桥区分。因此当前比较应称“候选可用条件下的构筑资源适配”，不能称整套牌真实强度。

## 辅助标注与后续优先级

DeepSeek只抽取机制、条件和疑问。V6固定完整规则与12组示例为独立共享前缀；未见文本四批全部成功，16张结构通过，总用量80714 tokens，后续批观察到缓存17024/17024/17152。20探针有真实目标域错误，校验失败不等于调用未执行；不重新抽样直到得到同意结果。

下一步按通用机制覆盖扩展，不为讨论卡拟合：生成物用格子与明确属性覆盖约束；死亡/精确击杀/普通击杀分开绑定成功事件；多敌攻击频率和真实反制资源转换补局部回应；构筑抽牌质量通过冻结的统一报价＋有限支付机会计算边际，避免递归自证。独立盘点提示Add/Summon族数量多，但引用物自身的关键词/生命周期不能只靠一条regex消失。

## 验证

当前151项检查通过，覆盖共同支付门槛、减少费用的单调约束、法术目标范围、联合目标非贪心选择、伤害实例、账目求和、低HP入口一致性和缓存输出副本隔离。缓存隔离在同一参考对象内，只用局部窗口真正读取的字段；卡名、费用、未用手牌身份不作为额外质量信号。

运行 `python -m unittest discover -s analysis/monster-value-heuristic -p test_*.py`。独立复核见`coupled-integration-review.md`和`resource-deck-review.md`；151通过验证的是这些具体局部不变量，并不证明当前体系已完成全卡池可靠评价。
