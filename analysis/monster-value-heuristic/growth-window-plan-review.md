# 共享属性变化与生命周期窗口：设计复核

2026-10-08。只读 `context_value.py`、`combat_increment.py`、`coupled_magic.py` 与既有窗口复核；不改代码、不调用 API、不运行整局模拟。本文复核拟议方案，不宣称实现或测试已经完成。

**三路共同窗口适合隔离实际成长、沉默与关键词的交互，但原样 `F(printed)+U(P1)−U(P0)` 不能自动证明没有重复定价。** 若 F 是根状态下已含普通身体使用/寿命的价格，原三路还会额外计普通属性带来的下一次正常攻击收益。建议保留当前 F 标尺，以“同样成长后的永久普通身体”作归一参照；否则需要把所有普通身体都迁移到统一窗口标尺，并明确 F 只是窗口后的残值。这两种含义不能混用。

## 三路能改善什么，不能保证什么

现状纯 self growth 为 `(1−qSilence)×[F(grown)−F(printed)]`，没有显式存储已获得 modifier，也没有把成长后的身体与 Haste/Taunt 一起行动。直接乘 q 只能代表“沉默丢掉这段身材代理”的先验，不能描述攻击已经发生、成长改变生存线、对手现金不足或同一目标交换后的实际状态。

新窗口可以按一个绑定后的 modifier、统一伤害与攻击许可计算这些相互作用。ATK 过量收益依然由同一个 F 和合法目标决定；Taunt、Haste、Armor、Dodge 不再分别套独立常数。沉默发生后删掉 modifier，保留之前实际伤害和玩家 HP 后果，也比对全部增长再乘一个保留率清楚。

但这**不保证 Glyde 在前期一定变差**。当前模型评的是合法可支付后的部署；费用不足的情境没有估计留牌/等待成本。早期收入、付费后现金紧张、格子和后续恢复，不能仅靠一个身体回应窗口全部表示。已有 `EVENTS` 的 silence 权重按阶段变化，而 `combat.RESPONSE_WEIGHTS` 按角色变化；它们是不同先验。替换时必须选定一套共同响应分布，不能同时用旧 q 衰减、新 silence 分支再扣一次，也不能据预期排名选择权重。生存临界线有时会使前期增长更有价值，必须允许这种结果。

## 低成本核心架构：根价格不动，窗口只修 modifier 风险与额外行动

定义 `U(P)=E[Φ(该路窗口末状态)]`；所有路共享角色、回应分布、回应费用/可获得性、敌方初始场、玩家 HP、一次回应与一次下一己方攻击的边界。Phi 含剩余身体与已兑现玩家 HP/对手现金差，不含另一份初始普通身体奖金。

拟议三路记为：

- `P0`：原 printed 身体、无 modifier、无关键词。
- `Pmid`：实际 Magic 成长后的身体、携带可被清除 modifier、无关键词。
- `P1`：与 Pmid 相同 modifier，加真实关键词；当前 Haste 行动发生在未见回应前。

为保留当前 F 的“普通身体根价格”含义，再加一个便宜的合成参照 `Pref`：**初始 ATK/HP 与 grown 相同，但这些是其永久基础身体；无 modifier、无关键词。** 它不是另一个真实候选，也不新增 G/手牌；只是普通属性价值的归一对照。P0 可沿用缓存作诊断，主报价实际只需 Pref/Pmid/P1 三条；无沉默、无关键词时很多路可完全复用。

账本定义为：

```
ordinary_body            = F(printed)
joint_growth_body        = F(grown) - F(printed)
modifier_window_adjust   = U(Pmid) - U(Pref)
keyword_window_adjust    = U(P1) - U(Pmid)
gross                   = F(grown) + U(P1) - U(Pref)
net                     = gross - 本次实际支付费用
```

这样无沉默/关键词、Magic 只改变身体时，Pmid 与 Pref 完全一致，价格退化为 F(grown)。不能再叠旧的 `(1−q)ΔF`、另加“成长存活奖励”、减“普通死亡损失”或加击杀/多攻击奖金。对手为回应花的资源仍是对手效用差，不是我方金币到账。

原三路也可保留以下诊断，但不可又全加到主价：

```
raw_window_growth_delta       = U(Pmid) - U(P0)
ordinary_stat_window_delta    = U(Pref) - U(P0)
modifier_window_adjust        = raw_window_growth_delta - ordinary_stat_window_delta
```

上述恒等式保证重复的普通属性窗口项被相减，不能证明 F 已经是实战校准价格。这个方案仍是根身体标尺上的条件修正；它故意不以一次共同伤害重新惩罚所有普通身体，也不声称给出了完全局面化的身体寿命价格。

如果目标必须是“成长在该具体窗口能兑现多少”，应选另一条路线：所有普通身体都用同一局部窗口计算，统一比较对共同环境的 ΔΦ，将 F 解释为窗口结束后继续价值，并重新核对 Aaron 标尺。此时不要再加初始 F(printed)。范围依然可以是一个回应窗口，不需整局模拟；但这会改变所有普通身体的标尺，成本和回归面更大，不宜静默只对成长牌更换。

## 最小状态与安全域

无需完整游戏对象。每个 actor 增加 `printed_attack/printed_max_hp`、`current_attack/current_hp/max_hp`、已获得 modifier 和当前关键词；Magic 数量在打出时绑定一次。例如“打出后手牌数×1”是已获得数量，不能在未来手数变化时自动重算成长。

先支持新鲜主体、非 base 属性的正向 self ATK/HP modifier；外部友军、随机目标、自伤、吸血、Dust、持续光环、base ATK/HP 变更与再次成长仍 partial。明确写 base 的增长不可用恢复 printed 的规则清除。

无当前攻击、沉默分支在任何伤害前、主体 `current_hp=max_hp` 时，去 HP modifier 后的 fresh 重置可直接回到声明的基础 HP；之后的伤害保持实际结算。这里的“沉默清除该类 modifier”仍是模型支持边界，不能由方法设计升级为全部 Undercards 数值清除裁定。

Haste 不必一概拒绝：**只有有正权重、可支付沉默，且某合法当前攻击能让仍存活主体受伤，同时删除 HP modifier 的语义会分叉，才需要拒绝该情境的完整报价。** ATK-only 成长的沉默不会改变最大 HP；无接触伤害、silence 权重0、对手不足3G等情境也可以保持支持。死去主体是吸收状态，不能靠重置复活。

不能只删掉不明的 Haste 路线，悄悄把“等待”当完整最优方案。可将该情境标为 partial，或另给明确限制“仅延后政策”的报价；后者不能冒充全动作窗口价值。沉默单一回应后不应再凭空添加第二次敌方伤害；若另开“沉默后攻击”复合事件，必须三路共用且重新声明顺序。

## 三个能改变结论的反例

### 1. 相同最终身体，应通过无风险属性等价性

双方 HP30、敌场空、回应 `none=1`、无关键词/沉默，主体 9/7 在 Magic 获得 +1 ATK。对照为同费用、直接印刷 10/7 的无文字合成主体。两者打出后的物理状态、合法动作与未来已知作用完全相同。

若用原三路，下一回合两路分别打脸9/10且主体仍存活：

```
U(Pmid)-U(P0) = F(10,7)-F(9,7) + 1×玩家伤害权重
```

于是成长卡的价格比直接 10/7 多一份普通攻击收益；control 的现权重是0.25。这也会削弱既有过量 ATK 的边际递减：即使 F 的 9→10 增量很小，每级还额外加一个 face 常数。归一方案以 Pref=永久10/7 相减，返回准确的 F(10,7)。这是区分“账本可 telescope”和“普通属性未重复定价”的必要反例。

### 2. 共同死亡既不能额外扣普通身体，也要说明“兑现”与“根报价”不同

printed actor=2/2、Magic 仅 +1 HP→2/3，敌体=4/8；唯一回应为一次敌方接触，关键词和沉默均无。双方 actor 都死亡，对方均受2伤害并剩4/6，没有下一次主体攻击；所有末状态组件相同，故 `U(Pmid)-U(P0)=0`。

若声称计算这一次窗口的实际成长兑现，正确窗口增量是0，旧静态 `ΔF>0` 不代表已经兑现。若保留根 F 标尺，则 Pref=永久2/3 也走相同死亡轨迹，归一修正0，报价仍为 F(2,3)。这不是实际末状态价值，而是有明确普通寿命标尺的根报价。

此例迫使模型选择含义：不能一边保留全体普通身体的根 F，一边只对成长卡扣一次绝对死亡损失、宣称得到真实窗口寿命价值。若希望该场景所有主体的价都趋于零，应统一迁移普通身体，而非增加仅成长卡的惩罚项。

### 3. 受伤 HP modifier 的沉默能改变 Haste 策略与报价许可

printed actor=2/2，Magic +2 HP→2/4并有 Haste；敌体3/2，对手3G，唯一回应是付3G沉默。当前 Haste 交换使敌体死亡、actor剩1/4。

删除 +2 HP 时，`cap_current` 得1/2仍活；`preserve_damage` 得−1/2死亡。前者可以再攻击并保留身体，后者不能；这足以改变是否应先交换、关键词增量及净报价。未确定裁定时不能平均两个结果，也不能默认给“先换掉敌怪再被沉默”更高分。

因此当前提议的拒绝受伤 HP 重置边界是必要的。若只增长 ATK、沉默无可获得性等，不能把同一个拒绝扩成所有成长+关键词都 partial。主动只选等待可给“仅延后政策”报价，但只要其他合法 Haste 路线仍触及未知，就不能称为完整窗口最优报价；支持范围与受限策略必须分别写出。

## 进入实现前的验收

首先确定 F 是根身体价格还是窗口末残值，选一个统一架构。默认低成本路线建议保留根锚并引入 Pref 归一。然后要求：无风险属性等价性；零 modifier 退化为现有关键词原语；零关键词不多计普通攻击；同一回应分布/预算/信息顺序；无旧 q 与新 silence 的双扣；实际付费一次；沉默不恢复历史玩家 HP、不复活死者；不明 HP 重置使情境明确 partial。

报告应同时展示 `ΔF`、modifier_window_adjust、keyword_window_adjust、普通属性窗口诊断与已支持/拒绝权重。早期或过量 ATK 的方向由这些共同反例与场景决定，不以 Glyde 或任何指定卡的预期排名作成功条件。
