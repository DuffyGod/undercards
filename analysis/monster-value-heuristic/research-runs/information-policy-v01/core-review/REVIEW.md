# 新有限物理核心审查，2026-10-17

这是新实现 finite_physical0.1.0，不是恢复遗失的 paid0.32 源码，不继承其覆盖率与旧测试凭证。主任务是让信息集策略拥有明确、真实付款的有限状态转移；扩充罕见效果不是本轮目标。

## 已纠正的错误路径

1. 初版允许 Snowdrake 选择自己吃 Magic 的 +2ATK。按用户确认的规则，玩家选择的 Magic 目标排除施法怪自身；自动 self 回调仍可作用自己。反事实：只有 Snowdrake 时空目标不被伪装成“不可部署”，保留未知；已有 Dummy 时唯一合法己方目标是 Dummy。
2. 原生 ID 只能证明印刷 COST，不能证明观察怪物的当前与 base COST。初版把三者都默认成卡面。现观察态缺这两项保持 `None`；Jerry 的减伤实际遇到源 COST 缺失或三种 COST 阈值真值不同时拒绝计算。手中显式当前价格决定实际支付，并与基础及印刷价格分别保留。
3. Silence 对 buff 后 ATK 或 maximum HP 的清理缺服务器证据。现只在目标有印刷身份、明确 maximum HP、当前 ATK/maximum HP 都等于印刷值时执行；DT 固有免疫保留。当前 HP 因受伤下降不被误判成 maximum HP 被改写。
4. 观察怪物的 maximum HP 不再从印刷值默认为已知。若没有明确 `max_health`，治疗怪物时保留未知。根状态显式 silenced 时也不恢复印刷 Taunt；只有显式传入的当前 statuses 能保留。
5. 旧 29 测试在新增守卫后有 2 个输入不完整而失败：Jerry 伤害源没给观察 COST，Silence 的目标没给印刷身份与 maximum HP。测试输入已补全；没有放松守卫来恢复通过。
6. 快照中非卡牌记录的 `card_type=None` 最初会造成 AttributeError。现转为 UnknownMechanic，静态遍历可完整记录拒绝原因。
7. 末次自然抽牌若疲劳致死，停止余下边界事件；不继续执行可能产生不实终局信息的后续抽牌。

这些变化在不同卡牌共享的目标、数值、观察信息与支付规则上生效，不用单卡分数补丁来制造预期结果。新增 18 项针对性反事实，总计 47 项核心测试实际重跑通过；该数字不包含主侧信息集求解器测试。

正式批次启动前补齐协议守卫：顶层配置采用正面白名单，`max_plays`、`hp_certificate`、未实现的 fatigue 参数或拼错字段均返回未知；资源、HP、金币、牌价、观察 A/H 与阶段资源必须为实际整数，不接受布尔、字符串与小数的 `int()` 截断。四项新测试含多组反事实；疲劳首次致死停止后续抽牌的现有测试再次通过。此次没有扩充卡牌机制。

## 明确保留的限制

- 空目标必选怪物 Magic 能否无效果出场未由服务器证据确定，现返回未知。
- 仅支持有限完整文本语法；未支持的 Dust、Need、递归、随机选择与复合后半句不退化成裸身材。
- 支持固定四阶段 own/enemy/own/enemy；金币增长与抽牌均来自明确参数。根余额不假定自动刷新；有序牌库由本批显式给定。
- 自身加 ATK 的 Turn start 与抽牌交换可交换；回血回调与疲劳可能不可交换，遇到这组情况保留未知。没有把服务器未证实的结算顺序当成事实。
- Worsening 严格完整文本保留 Delay；生效后记录目标公开物理 key，回合结束若目标死亡且源非 Generated，生成 2G 的 Generated 副本，副本实际付款后才能使用。满 7 手 Add 的规则分歧保留未知。普通自然抽牌的七手上限来自快照规则说明。
- 初始 `hand_generated`/`opponent_hand_generated` 为严格布尔数组，必须与物理手牌数匹配；省略标记默认非 Generated，是本有限实验的显式假设，并非对任意实战手牌来源的推断。自然抽到的牌也按非 Generated 处理，本批不自然抽 Worsening，尚未模拟 deck 内 Generated 历史。
- 敌方 Delay 队列的 Generated 来源标记在观察键内隐藏；不同来源的世界只有在实际生成导致公开手数变化后才可能区分。两世界的根观察与施法后观察一致、Delay 结算后观察不同，已有针对性验证。
- Lady Garf 仅观察态允许其已经完成、且没有持续回调的严格 Magic 模板。不允许从手中无效果支付它，也不重放历史随机获取。
- 对手策略并不已知己方手牌。本轮主求解器只控制己方可观察信息集共同策略；敌方额外知情所产生的保守性应另行说明，不能宣称完整双向均衡。
- 静态覆盖脚本只说明编译接受完整卡面，不说明该卡所有对局状态都被证明，更不等于跨全部卡池通用排名。

## 分工与证据

本核心及其测试由核心代理实现；主侧独立实现信息集求解器；反例代理的原生 Jerry/Aaron 小局枚举不导入这两套程序。三者一致才构成该实例的较强验证，不把代理一致意见替代执行结果。跨 SOUL 的 Penetration/Worsening 构筑问题由反例代理发现，正式隐藏手牌应标为共同公开生成历史得到；原生 Worsening 的再生成另列规则探针，不能与该正式隐藏菜单混报。
