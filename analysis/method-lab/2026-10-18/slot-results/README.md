# 固定槽位、有限付款菜单试验

这是一项当前回合截止的卡槽边际研究，**不是整卡质量或实战胜率**。未来tail=0，无敌方回复；未实现的未来Dust折扣、防护及触发器储备没有混入数值。主参考为Froggit #2，Moldsmal #4仅作独立参考敏感度。

## 共同目标

`M(x) = max_同一可支付物理菜单 [整个己方终点身体F + 敌方身体F下降 + 已兑现玩家伤害价格 + λ×剩余Gold]`

`槽位边际 = M(候选) - M(参考)`。

现金及支付都已经进入这个比较，不再扣一次候选费用。背景是真正无效果的普通身体；其前置、后置、不出三种选择与候选的当前目标在随机链揭晓前固定。手牌按实际已付出的前缀移除。所有物理副本最多付一次。

slots指候选和背景可用格子，其他格子是共同惰性占位，其身体价相消。所选机制不计这些友军数量或为其增益，故排除Broken Car/Snowdrake；排除Bench以避免抽后身份及付款问题。Archer的2/3 Clover无空格时采用显式召唤失败假设，保留原合法Play；Blockler B死亡后O使用释放格。

## 文件与重现

- `slot-primary.csv.gz`：22,140条主参考记录。
- `slot-reference-sensitivity.csv.gz`：22,140条替换参考记录。
- `slot-summary.csv`：按菜单、需求组、λ、候选及参考汇总；现金和格子层各等权，32个宽场样本各1/32。不是实战频率。JSON副本由脚本本地生成，仓库省略重复副本。
- `slot-design.json`：完整冻结敌板、源SHA、参数与压缩导出SHA。
- `slot-verification.json`：网格不变量结果。
- `delivery-checks.json`：压缩往返/确定性核对及本轮8项手算测试实际结果。

在本目录的父目录运行：

```text
python -B -m unittest discover -s . -p test_slot_value.py -v
python -B run_slot_study.py
```

两个大CSV的gzip共583,273字节；不含路径、原文件名、当前时间戳。原CSV可仅留本地，标准库gzip可读。确定性重压缩与解压往返均已核对。

## 使用率与零增益等价解

`candidate_used`是确定性选择出的菜单是否使用候选。`candidate_strictly_improves_background`是`M_candidate-M_background_only>1e-10`的必要使用质量；`candidate_gain_over_background`保留其实际差值。`candidate_selected_without_strict_gain`识别零增益tie产生的虚假使用率。

相差不超过1e-10的数值等价菜单保留先枚举者；不出候选菜单在前。本轮44,280条记录没有选出却无严格增益的候选。这个规则消除了浮点加法顺序让零净收益Aaron看似被部署的伪差。使用率不是玩家实际使用率。

## 三个固定实例

背景均为`[Froggit #2, Candy Dish #187, Aaron #15]`，即`three_plain`，现金残值λ=0。

1. **付款竞争与同计划ATK边际。** 6G、2格、敌三个3/2，候选Vulkin。候选菜单为Vulkin用Magic移除一个3/2，再打背景Froggit，值8.022854；参考菜单仅打背景Froggit+Candy Dish，值5.687414。槽位边际2.335440。固定原菜单将Vulkin ATK+1，值增加0.414486；重新选菜单的增量相同。不是靠换打法才产生价格变化。
2. **有限格子与背景替代。** 上例改为1格，参考改选背景Aaron，值5；Vulkin单独的值5.784639，槽位边际降为0.784639。额外一格使槽位边际增加1.550801。身体、Magic与已有背景没有各自单独最优后重复相加。
3. **付不起造成的真实平台与替代损失。** 4G、敌三个3/2，候选6G Archer无法部署。1格时两边均打Candy Dish，槽位边际0；2格时候选侧仍只能得到3.449199，参考侧可打槽位Froggit+背景Froggit，得到4.476430，故槽位边际−1.027231。候选ATK+1不改变这个短截止结果。加1G后两边可打Froggit+Candy Dish，槽位边际回到0。

另一个平台：6G、1格、空场，Glyde在当前四张手牌中最多成长为5/5；背景Aaron为6/5且更便宜。两边均选择Aaron，槽位边际0。Glyde ATK+1到6/5仍只追平，故该菜单边际依然0。这不是说Glyde潜在部署身材没有价格增量；它说明在这个具体竞争菜单中增量尚未改变可实现的最高值。

## 范围与局限

15候选、3个背景菜单、3个手算敌板，并在主菜单增加32个由冻结aggro卡池分层权重独立抽出的三体需求。现金4/6/8/10，格子1/2/4，λ=0/.5/1。它们是公开设计网格，不是抽到候选后的环境频率。

F沿用既有标尺；没有新的单卡价格拟合。λ=0意味着这个有限目标不评价截止后现金，λ=1则给留存Gold完整价格；两者都只是明确目标。未用手牌的截止后期权没有报价。Lesser Dog/Sad Dragon等未来能力差异在本试验中可能消失，不能据此断言整卡同质。抽样板上的差异不等于外部实战验证。

固定原菜单ATK增量不超过重选菜单增量、增加现金或格子的各自最优值不下降、同槽身份36例，全部通过。**槽位边际本身不要求随现金/格子单调**：参考卡也可能从新增资源中受益更多。
