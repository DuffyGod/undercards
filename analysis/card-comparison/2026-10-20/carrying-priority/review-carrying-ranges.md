# 携带区间启发：对“中费主体、高费例外”的独立挑战

2026-10-20。只读既有19/20日研究、规则与定向卡面；未运行旧实验、未生成牌组、未用价格设置或子智能体投票当Gold。卡面来自2026-10-05整理快照，未保证现行服务器一致。本文是待验证的通用携带准则，不能当作已测实战费用榜。

## 应交付的默认建议

在未知具体卡组、没有稳定额外补牌/减费来源时，可先优先研究并携带**实际支付费约3–6G、能独立形成有效身体，并同时做即时干预或补回手牌的怪物**；以能兑现的2–3G单位覆盖开局和补费；7G以上保留给能压缩多项行动、反复交换、占用较少手牌/格子或形成终结的高密度牌。

这是有理由的工作假设，而非“3–6G已证明最优”。真正有证据的部分是：金币、手牌和格子同时限制行动；高费未必较晚可用；额外牌的机会价值可使19/20日的站场排序反转。尚未证明费用边界3/6/7是最优，也未测各类应放几张。不要为填完整建议而输出任意配比。

| 实际费用/角色区间 | 初步携带优先级与条件 | 应淘汰或降级的理由 |
| --- | --- | --- |
| 0–2G普通身材 | 开局兑现、补费、保护关键大体、推动明确引擎时优先；不能因便宜就自动主轴 | 后期一张牌和一个格子只换很小身体，且不补牌、不跨关键交换阈值 |
| 2–3G有有效攻击或防护的单位 | 需要早场、能换到敌关键小体、或持续补牌时可成为主轴 | 低攻厚血不能阻止打脸；只会站住但不能争夺交换，不等于前期安全 |
| 3–6G独立站场＋即时作用/补牌 | 缺少其它信息时的优先主体候选：单卡覆盖更多窗口，既能出又能续 | 附带条件经常不成立；身体不能跨对手击杀/反杀阈值；额外费用只买无用途数值 |
| 7–12G高密度单位 | 能可靠活到兑现、能补回等待损失，或牌/格子已是瓶颈时提高优先级 | 只比中费多一点身材，且无合理重复交换、回复、回场或终结路径 |
| 目标型/条件型跨费用牌 | 按它解决的敌方威胁与替代方案决定携带，不能只按最佳出场收益 | 满足时机虽赚，却难以在需要时找到目标；等待占槽的代价未识别 |

“独立”不表示必须没有目标；Vulkin的普通身体及敌体/玩家多种Magic目标使低条件窗口较宽，Toriel则有更明确的高攻击目标需求。携带判断不能把条件牌强制打在差时机后扣光收益；应公开无法兑现时占掉哪个携带槽。

## 不用先选ρ，也能说明纯低费的长期资源瓶颈

按公开的起手3张、每己回合（含t1）抽1张约定，无额外抽牌、生成、循环、Program或其它花钱渠道时，到己t=n最多使用`n+3`张牌。若这些牌的实际费用均≤c，累计付款至多`c(n+3)`。普通先手t10累计自然金币56、最多见13张牌，因此：

| 所有牌的实际费用上限 | 即使把见到的牌全部打出，t10仍至少剩余 |
| --- | ---: |
| 2G | 30G |
| 3G | 17G |
| 4G | 4G |

四格、卡手、必须保留的反制牌只会进一步减少可花金币。这是资源约束的解析上界，不是模拟结果或胜率结论：便宜牌可能在t10之前已取胜，留钱本身也不等于失误。它说明**打算长期争夺场面的纯低费结构，需要补牌/循环/额外花钱渠道才能继续转化自然收入**；增加裸低费张数不能突破每回合到牌速度。

这也给出费用推荐的条件：短期竞速有理由优先廉价即时威胁；若预期长期而缺额外到牌，则优先单牌密度或自补手牌的中费主体；有明确的持续补牌/生成时，低费主体的限制放宽。Bravery等额外生成、Fishing Rod等补牌会直接破坏上述单抽前提，不能沿用这张表否定它们。尚无真实比赛持续时间分布，不能据表计算低费应带几张。

## 哪些真实卡会推翻简单费用口诀

### 补牌怪能推翻“便宜牌总是更耗手”

实际读取卡面：Bench #243为5G5/5，Magic抽1；Chilldrake #12为4G4/5，Magic选择抽怪物或法术；Fishing Rod #225为3G3/4，己回合末抽1。手有空间、牌库有合格牌且没有额外Turbo等干扰时，它们第一次出场可补回使用的一张手牌，而Aaron #15的5G6/5净少一张手牌。

因此3–5G“站场兼续航”类是比“只比较单大怪与多小怪”更应优先的携带候选家族。这里不需要先把抽一张定成0.65或2 model-G；净手牌和身体阈值的差别本身就是有用解释。Bench多保留一张牌的同时少1攻，面对6HP敌体可能失去一击击杀；不能据补牌就判其处处胜Aaron。Fishing Rod的后续每次抽牌依赖留场，不能预支为无限资源。

### 高费也可凭重复交换，而非必须靠入场Magic

Knight Knight #17为9G5/9，自己攻击并存活后，按实际造成伤害治疗自身。若它能在己方主动攻击中反复杀小体并回复，真实每牌回报可以超过一次落地的5/9；这类高费没有即时Magic却有合理单卡高密度路径。当前一轮敌方回应只结算敌主动攻击，不能把这个机制按0定价后证明其弱。

相反，Undyne #62的12G7/8与10次最低HP伤害/剩余Spear属于回场和行动压缩，不宜拿去代表普通高费白板。Toriel #8为8G6/4，削敌ATK至1并将削掉的攻击变为自身HP；它需要足够高攻击的敌体，不能用空场基线否定携带，也不能只拿最佳目标支持常备。

### 印刷费用分档会把发动机误归类

Vine #529印刷12G7/7，但每打出过一Plant就在手中降1G，最多降9；Berdly Statue #761印刷11G6/7、Taunt/Haste，按此前打出的1G以上TOKEN减费，最多降8。两者可能在3G兑现，但需要此前已支付的启动牌、手牌和时间。通用模型须用**可达的实际支付费区间＋启动负担**，不能将其纳入裸12G/11G一栏，再推荐降低高费数量。

Napstablook #53印刷3G5/5，但己回合末先掉1攻，第一敌回应通常面对4/5，且攻击继续衰减至0会死。它是低费即时身材候选，却会推翻只看印刷ATK+HP/费用的筛选。适合早压的假设与适合长期站场的假设不同。

## 身材区间应该按阈值，而非简单总和解释

敌体(a,h)面前，普通友体(A,H)同时满足`A≥h`与`H>a`时，才能在一次普通互打后“杀敌且留体”。同总ATK+HP不保证同样结果。既有两个5/7探针中，Aaron6/5既不能一击清7HP，又会被5攻杀死；RG1的7/10能先反杀一个5/7并存活。这个门槛是可复用的携带理由，不能迁移成环境里到处都有5/7。

因此建议输出“优先能跨哪些共同攻击/HP压力带的怪物”，例如目标敌体有4–6HP时，4攻升5/6可能改变击杀数；敌体攻击为3–5时，自身HP越过4/5/6可能改变留体。压力带目前是可选择的条件，尚无频率标签，不应宣布某一ATK/HP矩形全局最优。

Taunt/Dodge/Armor和SOUL也会跨门槛：Dummy0/4以1G让关键大体免受一次目标攻击，是低攻小体的有效携带用途；Kindness的+1HP可改变恰好致死；Justice会移除低HP目标，使高攻击小体或即时伤害的用途变动。不能只用“防护值折成多少身材”概括这些角色。

## 低成本、能改变携带建议的验证优先级

1. **先验证3–5G站场补牌是否适合作为默认主体。** 同一实际到牌/自然金币序列，把一个槽分别放Aaron、Bench、Chilldrake或Fishing Rod；保留抽到的真实下一牌与手牌上限，先比到下一个己方行动窗的身体、实际可行动菜单和生存，不先给抽牌统一价格。敌场覆盖跨5/6HP击杀阈值、低攻能重复交换、以及可杀引擎的即时惩罚。若补牌牌常因失去关键攻击而丢场，默认优先级要降。
2. **先验证高费的等待损失是否能被回报覆盖。** 同一公开到牌序列，允许2–3G早出、4–6G中出和等待9G；早出单位必须真实攻击、交换或死亡，不能只在截止摆到同一空场。先用普通身体即可检验“中费主体”假设，再加入一个明确的高费重复交换机制，避免把模型未支持当弱。
3. **用两种极端资源条件挑战同一个建议。** 无额外补牌且四格已紧，与有明确补牌且常有空格；如果低费/高费排序在两者间反转，建议应输出条件分支，而不是取平均。额外手牌ρ的已存反转是研究线索，不是真实ρ估计。
4. **条件牌先问替代需求。** 对Toriel类记录“目标攻击多大、几次窗口内能遇到、其它携带牌能否以更少等待完成相同控制”。仅有单期目标频率不识别持有成本，沿用19日的时间相关反例，不重跑它。

当前不足以给真实费用配比，但足以给一个可操作的默认筛选：优先查找有效早场和3–6G独立站场/续航主体；高费保留给明确单卡密度，低费保留给明确早期和组合用途；任何跨费率推荐都同时检查实际到牌、四格、净手牌与关键交换阈值。把这个建议写成可被上面反例推翻的工作假设，比输出未经验证的“最佳曲线”更符合现有证据。
