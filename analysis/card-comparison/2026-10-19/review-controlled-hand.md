# 实际手牌干预：独立中心手算复核

2026-10-19。对应同目录 `controlled_hand_probe.py` 与冻结结果 `controlled-hand-probe.json`。

本复核读取源码、卡牌原文及已保存结果，另依据参考身体公式手算中心端点，未导入或执行旧估值核心、未重跑旧研究。本文件保存已经完成的复核，不新增实验。独立物理推导覆盖中心实际玩法；其他参数范围来自读取主探针结果，不能称为全部参数的独立物理验证。

## 条件与付款分解

敌方固定三个普通3/2数字身体，现金6G，两空格。背景由 `[Froggit, Moldsmal]` 改为 `[Froggit, Moldsmal, Aaron]`。五张焦点均6G，初始手牌合法；焦点出场后的手数从2变3。

这是两个初始手牌条件之间的干预比较，不是对局中免费获得Aaron的行动，也未给其获得成本报价。新增真实卡牌同时改变焦点手数机制和背景替代菜单，应分别归因。

所有背景均需正费用，故6G焦点出场时不能再支付背景。设 `B(λ)` 为只出背景的最佳当前值，`D_c(λ)=A_c−6λ` 为焦点单独出场的最佳条件值，则：

`M_c(λ) = max(B(λ), D_c(λ))`。

这里省略了两侧相同的初始现金项 `6λ`，不是额外扣一次费用。焦点诊断路线不是强制采用的策略，实际可以不出焦点而选择背景。由于剩余现金不足，不能免费先打背景再花6G出焦点以调手数。

## 中心身体标尺及独立端点

按保留的共同参考身体分布，中心 `face_share=.2`、阈值系数 `.4`、锚 `F(6,5)=5`，独立手算得到：

| 身体 | F |
| --- | ---: |
| 2/3 | 2.238215 |
| 3/2 | 2.159945 |
| 3/1 | 1.530878 |
| 3/4 | 3.145113 |
| 4/4 | 3.624694 |
| 5/5 | 4.684963 |
| 6/5 | 5.000000 |

Piranhas攻击杀一只3/2，Dodge消耗并保全自身4/4。随后1伤随机打中剩余任一同质3/2，留下3/1；该伤害未击杀，因此不继续连锁。两种随机目标的资产相同，独立端点为：

`A_Piranhas = F(4,4) + 2F(3,2) − F(3,1) = 6.413707`。

手数2时，Archer的2伤恰好击杀一个3/2，Bullseye留下2/3 Clover，与本体3/4共同占两格：

`A_Archer,hand2 = F(3,4) + F(2,3) + F(3,2) = 7.543273`。

手数3时，3伤仍移除同一只3/2，但过量击杀不触发Bullseye：

`A_Archer,hand3 = F(3,4) + F(3,2) = 5.305058`。

条件端点损失恰为 `−F(2,3)=−2.238215`。两空格足够，本次不是格子不足或召唤失败。

Glyde从4/4变5/5，条件身体报价增加 `F(5,5)−F(4,4)=1.060269`。新增背景Aaron为5G的6/5；当前身体标尺下更高且更便宜，所以Glyde的潜在身体增值不保证提高实际菜单的严格增益。

## 中心实际选择及归因

以下数值读取冻结结果，目标仍省略共同的 `6λ`，取 `λ=.5`：

| 实际最优菜单值 | 原背景 | 加Aaron |
| --- | ---: | ---: |
| 仅背景B | 2.398160 | 2.500000 |
| Piranhas | 3.413707 | 3.413707 |
| Archer | 4.543273 | 2.500000 |
| Glyde | 2.398160 | 2.500000 |

Archer可以改出Aaron，故实际菜单只下降2.043273，少于焦点条件端点的2.238215。中心参数下新增背景后的焦点出场与Aaron交点为 `λ=.305058`；交点以上不再采用Archer路线，不能描述为被迫低效出场。

Piranhas−Archer中心差额由−1.129566变为+0.913707。Piranhas的绝对当前菜单值不变，但其相对背景的增益由1.015547降至0.913707，减少0.101840，原因完全是背景变强。Glyde总菜单值也随背景增加0.101840，但相对背景的严格增益仍为0。

这区分了焦点条件报价、实际可选菜单、相对背景增益，三者不得互相替代。

## 范围读取与明确限制

主探针冻结的九组共同价格设置及 `λ∈[0,1]` 上，Piranhas−Archer差额原为 `[-1.282368,-0.911549]`，加入Aaron后为 `[0,1.142525]`。这些范围是读取主产物，不是本复核独立重算全部参数。应表述为“Archer严格领先变为Piranhas弱领先”；部分价格下共同背景会压平两者，不能称全部压力点均严格反转。

报价限于当前截止、普通数字敌体、无对手回应、无玩家生存约束；未来能力不报价。Lesser Dog与Sad Dragon在这一投影中相同，不代表整卡等价。九个共同价格设置不是全部连续身体参数的全局证明；λ的连续菜单比较也不是实战校准。上述替代损失不能称为跨回合持牌成本，也不构成卡组推荐。
