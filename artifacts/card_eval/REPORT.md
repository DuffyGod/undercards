## 实际可用的入口

安装[wheel](dist/undercards_card_eval-0.2.0-py3-none-any.whl)，Python3.11+和NumPy：

```sh
python -m pip install undercards_card_eval-0.2.0-py3-none-any.whl
card-eval inspect Bench
card-eval assess Bench "Fishing Rod" --reference "Rock Pet" --samples 64 --output my-results
card-eval check --input my-decks.json
card-eval evaluate --input my-decks.json --output my-deck-results
```

也可在源码根目录执行`python -m card_eval ...`或安装`python -m pip install -e .`。[输入示例](../../examples/card-eval-request.json)、[实际示例输出](example-result/report.md)及[安装后输出](installed-example/report.md)均已保存。包内包含冻结规则原语、卡面快照和共享模型，运行不依赖研究目录或Git工作区。

与旧入口的实质区别是：双方各25张逐卡牌表，费用/攻血/机制逐一执行，不再把背景限定为small/anchor/draw等抽象角色。支持不同SOUL的实际被动、指定替换实体、任意受支持的参数/机制组合、结构化预检、机器可读结果与人可读报告。未上手、留手、等待、满格、烧牌与受罚进入完整胜负分母；区间按同种子的座次配对，不按决策数计独立样本。

正常入口使用三种声明的语义参考策略检查条件敏感性；这是有边界的启发式比较，不是最优对弈或真实环境总分。学习模型没有通过门槛，显式指定learned会返回`unqualified_policy`与空评分；`--experimental-model`才会启用诊断，且不给方向推荐。未实现卡面同样返回原因和空评分，没有把未知效果填0。

`result.json`逐对手/逐策略报告胜负差、配对区间、机会诊断和未决完成界；不平均成未经声明的Gold价格。只有完整且足够的样本、跨请求条件一致的严格区间才给有限条件方向；否则返回依赖对手/打法、证据不足或实验诊断。虚构语义参数会明确标注，不能借用真实卡名冒充原卡面。

## 学习改进尝试与独立失败

首批显式牌组训练见`v2/`：512局模仿、384局DAgger和1536局PPO，共2432个新模型终局，109594条决策。开发结果明显弱于语义规则。检查后发现模仿初始化混入不同打法的标签，且出牌/攻击共用源卡数值通道，提出监督目标和表示干扰的假设。

修订版见`v3/`：从既有日志读取43627条决策，统一按只看当前信息的race教师重新标注，保留12288条重编码样本；**没有重放这些旧牌局**。增加独立的出牌/攻击源卡通道，再以新牌序完成1536局PPO和66813条决策。价值只用HP终局±1，未引入固定Gold或生命差真值。

检查点仅由新开发集选择，选中`ppo-096.npz`并先提交，再执行尚未使用的64个最终种子、两座次和五种政策。最终3200个槽位有3个预算拒绝，保留为未知；其余到模型HP终局。下表为相同我方/对方牌表与相同种子下的比较，范围是未决完成界而非置信区间。

## 规则与程序验证

14项产品检查通过，覆盖完整实体牌表、隐藏信息隔离、不同SOUL、复制上限、完整分母与等价负控、行动通道梯度、未实现输入和未达标模型拦截。安装包还实际安装到仓库之外，验证了普通比较、未知Glyde无评分、共享模型读取、默认阻止未达标模型和显式实验模式，见[安装验证](package-verification.json)。这些结果只证明程序合同，不证明策略优越性。

针对长期治疗僵局，从“25牌、自然抽牌、英雄上限30且不生成/回库”推导完成界：疲劳31会在开始治疗前杀死英雄。新入口允许60个己方回合，避免旧40轮产生假未决；这是支持域内的模拟完成界，不宣称服务器有60轮上限。一个合法的三Vegetoid开局检查确实超过40轮后才到HP终局。所有开发选择的原始记录已在40轮内终局，因此没有重放开发集改变选择。

冻结原语逐字节复用，来源与哈希在包内`_engine/manifest.json`。当前完整卡面编译只支持20张普通怪物及对应的参数/机制组合；其他卡面、其他SOUL、完整神器/换牌/种族/死亡/生成链仍未覆盖。沉默对修改属性的清理是显式假设。**因此当前不能输出可信的全卡池榜，规则覆盖与政策充分性都仍是目标差距。**

本轮核对的一手资料及采用/未采用的推断记录在[方法资料](METHODS.md)：DAgger的自身状态分布问题、PPO交互优化及RL统计不确定性。牌序区间不涵盖少量训练种子的随机性，更不涵盖规则错误。
