# V4：先区分动作表示、教师和价值目标

本轮目标是减少导致 V3 失败的关键不确定性，并把可复用学习后端接入评估程序；不是再做一次相同 PPO，也不以新增牌局或通过测试数量作为成功。V3 最终留出 `1210000..1210063` 已退休。本轮不改变规则引擎、20 张完整机制实卡覆盖或未知机制拒绝机制。

## 可核对的资料及采用范围（2026-10-31 查阅）

- Zambaldi 等，[Relational Deep Reinforcement Learning](https://arxiv.org/abs/1806.01830)，2018。原文使用自注意力推理实体关系，研究效率与迁移。本轮只采用关系归纳偏置：共享参数评价来源、目标和公开局面的关系；线性排序器不是该论文注意力网络的复现。
- Chandak 等，[Learning Action Representations for Reinforcement Learning](https://proceedings.mlr.press/v97/chandak19a.html)，ICML 2019。原文学习行动表示以利用行动间结构。本轮使用规则可核对的语义关系，不宣称复现其学习嵌入算法或收敛结果。
- Sutton/Barto，[Monte Carlo Methods，作者课程材料](https://people.cs.umass.edu/~barto/courses/cs687/Chapter%205.pdf)，第 1–2、9–11 页。价值依赖后续执行的策略；从该策略的完整回报估计策略价值。本轮将确定性行动器冻结后重新收集终局标签，训练独立胜率头，避免把异质旧行为的结果当新策略的价值。未终局不产生标签。完整教材 PDF 抓取因文件大小失败，改为核对作者课程材料；未使用失败抓取作证据。
- Hausknecht/Stone，[Deep Recurrent Q-Learning for Partially Observable MDPs](https://arxiv.org/abs/1507.06527)，2015/2017。循环记忆可整合观察历史；原文并没有保证所有任务均超过历史堆叠。本轮仍只有有限公开历史，不能称为信念状态或已解决部分可观测；先判断公开动作关系是否已形成更基础的瓶颈。
- Heinrich/Silver，[Deep Reinforcement Learning from Self-Play in Imperfect-Information Games](https://arxiv.org/abs/1603.01121)，2016。NFSP 在不完全信息游戏中结合策略平均与强化学习；共同训练胜率不是稳健性证明。本轮加入训练未见的保留资源对手和 guard 对手，不把这些有限反制测试说成 exploitability 或纳什保证。

这些资料支持要区分的问题，不直接证明 Undercards 上的性能。

## 预定方法

1. 复用 V2 warmup+DAgger 的决策前观察，不重放旧牌局。仅多合法行动的决策参加同一个 12,288 容量固定种子 reservoir；完整来源、SHA256 和抽中决策索引保存。重新因果标注 race、guard，不使用行为的异质胜负训练 actor/critic。guard 的选择依据是 V3 最终测试前已有的 `v2/development-reference.json`；race 为教师消融。
2. 2×2 对照：相同观察分别训练原 V3 MLP 和公开关系线性 softmax 排序器；两个教师分别学习。MLP 固定 10 epoch、相同样本，禁用价值损失。关系模型固定 L-BFGS 上限、正则化，不按结果增加迭代。训练计算量不相等，记录耗时；对局共用每决策 0.25 秒上限和 32 节点公开斩杀搜索。时间上限相同不代表实际消耗相同。
3. 关系模型直接选择任意合法行动，不是从三种固定策略中选一种。输入包括费用、攻血、即时击杀/存活、有效治疗、已知抽牌空间、公开压力、资源余量、可组合触发机制、手牌/场上位置；无卡名/ID/UID数值、教师选项或未来结果。阈值和表示仍有人为归纳偏置，不能把高模仿率说成自主学得最优策略。
4. `relational_guard` 在训练前固定为本轮主模型，不按 development 或 final 重选。V2 PPO 前 8 个日志提供未用于本轮拟合的状态分布动作诊断；按多行动/攻击分开报告，避免只有 end 的状态抬高准确率。新 development 牌序只用于诊断。
5. 冻结主 actor 后，使用训练池随机完整牌组，新生成 384 个训练、96 个 development、96 个 final 回合。仅 Actor0 的决策预测其终局胜率，对手是均匀 race/board/guard 混合；每局权重相同，局内按决策数分配，减少长对局过度加权。独立 logistic critic，正则化预定，不重选；保存 actor 指纹不变断言。使用整局聚类 Brier 与训练集常数先验比较，并报告校准。critic 尚不参与动作改进，不是 Q 值，也不是卡牌分数。
6. 新最终牌序检验三类实卡背景、训练未见数值、Taunt+回合末抽牌组合、完整牌组结构和未见保留资源对手。两座位成对、按牌序聚类，和 V3/race/board/guard 比较。未完成保留 0/1 完成界；不给未知记平局。每个条件都须以配对 95% 下界胜过全部三个规则策略且无拒绝才可通过原有门槛。不能因局部改进自动替换默认模型。

## 剩余边界

在开发价值误差已读、最终结果未读时，另冻结五参数 HP/场面/牌库差基线和按公开回合分段的次要诊断，源码提交 `7127d63`。它们只用于识别富特征是否有增益、全程预测是否掩盖开局无用，不用于选择 actor/critic 或重调参数。主指标及主模型仍按原设计不变；最终配对比较与完整覆盖见 `final.json`。

有限观察摘要不是完整 POMDP 记忆；对手混合和牌组分布改变时 critic 没有校准保证。一个训练种子的牌序 CI 不包含训练方差。关系特征不能补齐未知规则。全局卡牌评价仍需决策改进、真实机制覆盖、成套反制与替换实验验证。本轮失败、未收敛与不显著结果均原样保存。

本轮预检中止记录见 `../v4-preflight-failed/failure.json`。修正的唯一表示差异是己方施法目标的位置不再按敌方 UID 巧合匹配；未读取新开发或最终牌局结果，超参数保持原预定值。
