# V11：未来牌序目标与后悔值排序的2×2试验

目标仍是可用的通用卡牌替换评估程序。本轮检验V10零启用的两个竞争解释：单次隐藏未来标签是否过于不稳定；概率差平方损失与事后门槛是否未产生可执行排序。不是增加卡牌或场景计数作为进展。

## 实际核对的资料

- Ng与Jordan，[PEGASUS](https://arxiv.org/abs/1301.3878)，UAI2000，2013为arXiv归档时间。参考固定/共享随机情景比较策略与部分信息模拟的思想；本轮只对己方未观察未来牌序作离线干预，没有完整信念或该文理论保证。
- Strens与Moore，[Policy Search using Paired Comparisons](https://jmlr.org/papers/v3/strens02a.html)，2002。参考成对比较与固定情景过拟合风险；根、续局情景及最终验证分开，不能把同根的多条续局当多个独立世界。
- Nair等，[AWAC](https://arxiv.org/abs/2006.09359)，2020/2021。参考按行动优势加权更新策略及复用已有数据；实际实现是gap加权pairwise logistic加baseline交叉熵，不是AWAC，没有bootstrap critic或继承其经验成绩。上一轮的分类策略迭代资料继续作背景，充分信念、PSRO及学习后最佳反制仍未实现。

## 保持信息不变的目标干预

复用V10的128训练/32诊断开局、完整前缀、已选fork、合法行动、原始结果。原终局保留为指定原未来的参考，不重复计算，也不混进本轮均值。原fork在完整轨迹上回看抽样，条件分布可能受后续决策数影响，不能直接称其原未来是新目标的无偏样本。

每个fork，在原规则NativeGame重现并逐观察核对公共前缀，然后仅用离线生成器重排Actor0仍在牌库中的实体。两方当前观察、合法行动和对手私手/牌序的哈希必须不变；相同suffix在各行动之间使用同一实体排列。原始牌组、多重集、手牌、场面、历史、已烧牌及对手隐藏状态保持。离线采样元数据不传给网络。目标是这个明确重排干预后接V5的结果，不是最优Q或完整信息集后验；这里只积分一个隐藏分量，不能把对手固定的样本当充分信念。

另新增64训练/16诊断V5roll-in，按对手四类×两座位交叉平衡。输入前预指定2..5与6..12回合内的目标回合，在线取此后第一个合格多行动非已知攻击斩杀决策；缺窗口保持缺失，不按未来轨迹长短或终局补抽。这与旧回看fork是两个保留来源的根分布，分别报告。

训练各根4条新共享未来；诊断8条，1..4仅用于epoch选择，5..8仅报告目标/排名稳定性，不调参。同根suffix不是独立开局；统计按原牌序根世界聚类。未决原样保留，拟合时任一已用行动/前4续局未决则该fork四臂共同排除，不填零。未测合法行动的标签为NaN/mask，不冒充失败。

排列为有放回抽样。若新抽排列与原排列或已测排列完全相同，且干预行动也相同，则直接复用已保存结果（含未知），不重跑其后续；不是把原未来固定塞进均值，也不算新独立测量。完整UID排列、复用标记与唯一排列数随采样元数据保存，不给在线策略。

## 2×2方法与真实启用

四臂同555维有序输入、32hidden、17825可训练参数和初始化/更新预算，主臂事先固定regret_mean。

| 臂 | 目标 | 损失 |
|---|---|---|
| regret_mean | suffix1..4均值 | 行动均值差幅度加权pairwise logistic |
| regret_single | suffix1 | 同上 |
| centered_mean | suffix1..4均值 | fork内概率差平方 |
| centered_single | suffix1 | 同上 |

四臂都在**全部合法行动**上加weight=.05的baseline交叉熵作为策略正则，不是对未知行动赋零终局标签。部署直接选学习logit最大行动，无事后概率门槛；原32节点攻击斩杀保护不变。这改变了V10的训练/部署协议，V10只作失败背景，因果比较以新四臂为准。

固定L2=.0001、96epoch、64fork minibatch；16/32/64/96按诊断前4续局均值上的已测行动regret选epoch，平分选早。没有按最终挑臂、调低门槛或搜索更多超参。全合法选择的测量覆盖另报告，不能把未测选择当输计算收益。

## 开发门槛先于大最终

若门槛通过，冻结主actor后用新192完整轨迹训练自身74维V，与同数据5参数和旧V5比较；48开发只报告。新333策略最终为32牌序×两座位×八背景×五政策，335价值最终96牌序。要求全部背景相对四控制的配对95%收益下界严格正，且无未决；另报八背景校正。固定V5对手不是学习后的最佳反制，也没有重新认证V9搜索对照。
