# 独立价值最终的分阶段诊断说明

在2330000段价值最终尚未启动、所有模型与门槛已经冻结时补充此只读分析。主验证仍是design.json的配对干预原局面/动作后Brier；本分析不改变它，也不参与epoch/门槛/actor/臂选择。

既有采集器在96个新价值世界先保存完整roll-in，其中一半行为为V5、一半为race。只有V5行为的完整终局才能直接监督V5自身完整轨迹；race轨迹不重标成V5，未决终局不填值。复用采集器已经执行的V5完整轨迹，另按全部状态、1..5回合、6..12回合、12回合后和己方空牌库分别报告等开局Brier及配对误差差区间。所有子集仍属于同一批新世界，不能当独立重复实验。

若后期/疲劳没有样本，报告缺失及0个观察，不报告零误差；若种子少，区间只覆盖这些种子，不宣称后期泛化已解决。该诊断对应V8发现的监督覆盖问题，代码为card_eval/entity_value_profiles.py。

分阶段不足8个开局簇时只报告描述性均值，CI留null并说明原因，避免单一簇的退化bootstrap被误解为确定区间。该阈值在生成新价值数据之前固定，不用于挑选模型或样本。
